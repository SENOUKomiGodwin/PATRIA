# PATRIA Design Tokens

## Couleurs

### Principales
- **Vert principal** : `#0C6744` (barre latérale, boutons pleins, liens, barres de progression)
- **Dégradé vert → or/olive** : `#0C6744` → `#7A5C00` (bas de la barre latérale, panneau gauche de connexion)
- **Dégradé bouton connexion** : `#2D753A` → `#D7B305`

### Sémantiques
- **Jaune (écarts, alertes)** : `#F2B705`
- **Rouge (manquants, pannes, erreurs)** : `#C62828`

### Neutres
- **Fond de page** : `#F5F7FA`
- **Cartes** : blanc
- **Bordure cartes** : fine (couleur à préciser)
- **Texte principal** : sombre
- **Texte secondaire** : gris

## Typographie
- **Police** : Inter
- **Logo PATRIA** : Inter bold avec un « P » stylisé (si logo graphique non disponible)

## Composants

### Cartes
- **Coins arrondis** : 12 px
- **Bordure** : fine
- **Fond** : blanc

### Barre latérale
- **Fond** : vert principal `#0C6744`
- **Dégradé en bas** : vers or/olive `#7A5C00`
- **Logo** : PATRIA
- **Libellé** : « ESPACE DE GESTION »
- **7 entrées avec icônes** :
  1. Tableau de bord
  2. Biens
  3. Mouvements
  4. Inventaires
  5. Maintenance
  6. Rapports
  7. Utilisateurs
- **Bloc en bas** : « Besoin d'aide ? Consulter le guide d'utilisation → »

### Bandeau supérieur
- **Titre** : « Gestion du patrimoine public »
- **Informations** : service, nom et rôle de l'utilisateur

### Fil d'Ariane
- Navigation contextuelle

### Titre + sous-titre
- **Bouton d'action principal** : à droite du titre

## Marque
- **Nom du produit** : PATRIA
- **Slogan** : « Le patrimoine de l'État, maîtrisé »
- **Logo** : utiliser `docs/maquettes/logo.png` si disponible, sinon logotype texte « PATRIA » en Inter bold avec « P » stylisé

## États
- **Connexion impossible** : état d'erreur sur le formulaire de connexion
- **Session expirée** : message de session expirée
- **États vides** : soignés et cohérents avec le style
- **États de chargement** : spinners ou skeletons
